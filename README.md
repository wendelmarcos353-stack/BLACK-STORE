# BLACK-STORE
A BLACK STORE e um site de vendas de todo tipo de produto.

A estrutura ficará assim:

BLACK-STORE/
│
├── index.html          (loja)
├── produtos.html       (painel)
├── login.html          (acesso admin)
│
├── css/
│   └── style.css
│
├── js/
│   ├── loja.js
│   ├── painel.js
│   └── login.js
│
└── imagens/
│
├── Loja (cliente)
│   ├── Página inicial
│   ├── Produtos
│   ├── Carrinho
│   └── Checkout
│
├── Painel Admin
│   ├── Login
│   ├── Produtos
│   ├── Pedidos
│   └── Clientes
│
└── Banco de Dados
    ├── Produtos
    ├── Usuários
    ├── Pedidos
    └── Estoque
